  1. Google AI Studio 키 만들기 페이지를 열고 개인 구글(Gmail) 계정으로 로그인
    학교·교육청 계정은 막혀 있을 수 있어요
  2. 처음이면 이용약관 동의 창이 떠요 → 체크하고 계속
  3. API 키 만들기(Create API key) 누르기 → 프로젝트를 고르라고 하면 새 프로젝트에서 만들기(자동으로 생겨요)

연결 안 됨

카드 등록이나 결제 설정은 하지 않아도 돼요. 키를 잃어버려도 같은 페이지에서 다시 볼 수 있어요.

  1. Google AI Studio 키 만들기 페이지를 열고 개인 구글(Gmail) 계정으로 로그인
    학교·교육청 계정은 막혀 있을 수 있어요
  2. 처음이면 이용약관 동의 창이 떠요 → 체크하고 계속
  3. API 키 만들기(Create API key) 누르기 → 프로젝트를 고르라고 하면 새 프로젝트에서 만들기(자동으로 생겨요)
  4. AIza…로 시작하는 키가 나오면 옆 복사 → 아래 칸에 붙여넣고 연결

키는 이 컴퓨터에만 암호화해 저장하고, 일정 도우미에 붙여넣은 글만 구글 AI로 보내요. 카드를 등록하지 않으면 요금이 나가지 않고, 무료 한도를 넘으면 잠깐 날짜 규칙으로 찾아요. 무료 키로 보낸 글은 구글 서비스 개선에 쓰일 수 있어요.
