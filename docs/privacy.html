예람달력 개인정보처리방침

시행일: 2026년 10월 8일

1. 어떤 정보를 쓰나요

예람달력은 사용자가 구글 계정으로 로그인하면 구글 캘린더의 캘린더 목록과 일정(제목, 날짜·시간, 장소, 메모, 색, 알림, 반복 설정)을 읽고, 사용자가 앱에서 직접 추가·수정·삭제한 일정을 구글 캘린더에 반영합니다. 요청 권한은 https://www.googleapis.com/auth/calendar 하나입니다.

2. 정보는 어디에 저장되나요

일정 정보는 사용자 컴퓨터의 예람달력과 구글 서버 사이에서만 오갑니다. 개발자나 다른 서버로 전송·수집·저장하지 않습니다.

로그인 유지에 필요한 구글 인증 토큰과 화면 설정(색, 글꼴, 창 위치 등)은 사용자 컴퓨터에만 저장되며, 토큰은 윈도우 암호화 기능으로 보호됩니다.

3. 제3자 제공·광고

어떤 정보도 제3자에게 제공하지 않으며, 광고나 분석 도구를 쓰지 않습니다.

4. 구글 사용자 데이터 정책 준수

예람달력이 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 연결 해제와 삭제

앱 설정에서 로그아웃을 누르면 저장된 토큰이 지워지고 구글 접근 권한도 해제됩니다. 구글 계정의 서드파티 연결 관리에서도 언제든 해제할 수 있습니다. 앱을 지우면 사용자 컴퓨터에 남은 설정도 함께 지울 수 있습니다.
